# Homebrew tap for OpenCleaner

```sh
brew tap buihung1612/opencleaner
brew trust buihung1612/opencleaner   # Homebrew asks before using a third-party tap
brew install --cask opencleaner
```

[OpenCleaner](https://github.com/BuiHung1612/OpenCleaner) is a free, open-source (MIT) disk cleaner for macOS and Windows. This tap is updated with each release.
